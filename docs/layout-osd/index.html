PYTHON + GTK3 FOR XFCE / X11

Layout OSD.

See which keyboard layout is active as soon as you switch. A compact popup also tells you when Caps Lock turns on or off.

Install Layout OSD

Install on XFCE.

Use an XFCE session on X11. The commands below install dependencies on Debian or MX Linux, then set up Layout OSD for your user and enable XFCE autostart.

See the project README for configuration and removal.

Terminal
sudo apt install python3-gi gir1.2-gtk-3.0 libx11-6 x11-xkb-utils
git clone https://github.com/VladCraft228/linux-scripts.git
cd linux-scripts/xfce/layout-osd
bash install.sh
