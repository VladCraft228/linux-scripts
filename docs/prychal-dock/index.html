A dock for your
Linux desktop.

Prychal Dock keeps your favorite apps close, brings running windows into view, and tucks away when you need the space.

EVERYDAY WORKFLOW

From launcher to window.

▤

See what’s running

Hover for window previews. Switch to a specific window or close it directly from its card.

⊞

Arrange your apps

Pin favorites and drag icons into place. Move a running app between pins while it’s open.

▱

Drag files into place

Hold a file over a running app’s icon to raise its window, then drop the file inside the app.

◐

Make room when you need it

Use intelligent hide and tune magnification, colors, spacing, and borders from Dock Settings.

GET STARTED

Install on XFCE.

Use an X11 session with the compositor enabled and Rust 1.85 or newer. The installer builds the dock and adds it to your application menu.

Wayland support is planned. See the project README for prerequisites and uninstall instructions.

Terminal
git clone https://github.com/VladCraft228/linux-scripts.git
cd linux-scripts/common/dock-rust-prototype
bash install.sh
