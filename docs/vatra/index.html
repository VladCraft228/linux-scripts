See where your battery goes.

Track your laptop’s power draw, compare battery use across workloads, and tune CPU limits for battery and AC power.

Track power. Tune performance.

Battery readings

See charge, battery health, power and estimated runtime. Available readings depend on your hardware.

Power history

Compare minimum, average, and maximum battery draw over the last 1, 5, or 10 minutes.

CPU profiles

Review energy preferences and frequency limits before applying AC and battery profiles with TLP 1.8.

XFCE panel indicator

Add an optional panel item with a themed battery icon and a full-size percentage. Click it to open Vatra.

Install on Debian or MX Linux.

Use Debian 13 or a Debian 13-based MX Linux release and a current stable Rust toolchain. Build the main package first, then add the XFCE panel indicator if you want it.

For power controls, see the TLP setup instructions.

Build and install Vatra
sudo apt install git build-essential pkg-config fontconfig \
  libxkbcommon-dev libwayland-dev dpkg-dev desktop-file-utils
git clone https://github.com/VladCraft228/linux-scripts.git
cd linux-scripts/common/vatra
bash packaging/build-deb.sh
sudo apt install "./dist/vatra_0.1.0_$(dpkg --print-architecture).deb"

Add Vatra to the XFCE panel.

After installing, right-click the XFCE panel and choose Panel → Add New Items → Vatra Panel.

From common/vatra
sudo apt install libxfce4panel-2.0-dev libgtk-3-dev
bash packaging/build-xfce-panel-deb.sh
sudo apt install "./dist/vatra-xfce-panel_0.1.0_$(dpkg --print-architecture).deb"
