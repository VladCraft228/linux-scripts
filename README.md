# Linux Scripts

Small, practical Linux desktop tools with simple user-local installation.

## Common

### Linux Scripts Dock

A macOS-inspired XFCE/X11 application dock with a Rust engine and Qt Quick/QML
interface: magnification, pinned/running applications, window cards, launcher
imports, intelligent hide and persistent settings.

See [Dock](common/dock/) for dependencies, build, installation and validation.
Plasma Wayland is a future target and is not supported yet.

## XFCE

### Layout OSD

A macOS-style keyboard layout and Caps Lock indicator for XFCE/X11, built with
Python and GTK3. It provides compact rounded translucent notifications and
multi-monitor placement.

See [Layout OSD](xfce/layout-osd/).

## Project status

Prychal Dock and Layout OSD are available for XFCE on X11 and are under active
development. Visit the [Linux Scripts website](https://vladcraft228.github.io/linux-scripts/)
for demos and installation guides.
