# Linux Scripts

A collection of lightweight scripts and utilities for Linux desktops.

## XFCE

### Layout OSD

A macOS-style keyboard layout and Caps Lock indicator
for XFCE on X11, built with Python and GTK3.

Features:
- Keyboard layout notifications
- Caps Lock ON/OFF notifications
- Consistent 180x110 px popup
- Rounded corners and transparent background
- Multi-monitor positioning
- Lightweight X11 integration

See [Layout OSD](xfce/layout-osd/).
